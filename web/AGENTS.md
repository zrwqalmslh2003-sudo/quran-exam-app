# Qalon Web Agent Rules

- هذا الملف يحكم تطبيق React + TypeScript + Vite داخل `web/` فقط.
- طبقات الواجهة والمجال والتخزين منفصلة: UI لا يستدعي `fetch` أو `localStorage` مباشرة.
- `src/content/repository.ts` هي نقطة الاتصال الوحيدة بالشبكة.
- `src/domain/content.ts` يحتوي دوال pure فقط ولا يُعدّل سلوك عقد المحتوى دون قرار مستقل.
- لا backend ولا مصادقة ولا قاعدة بيانات في Web-1؛ التخزين المسموح هو `localStorage` لحالة المتصفح الخفيفة.
- يجب احترام عقد المحتوى الحالي ومصدر GitHub Raw فقط.
- لا تُعدّل تطبيق Flutter أو `AGENTS.md` الجذرية من فرع الويب.
- نفّذ أصغر تغيير آمن، وأضف اختبارات لكل طبقة جديدة.
- يجب أن تبقى أخطاء المحتوى البعيد محكومة وقابلة للتعافي، ولا يجوز استخدام HTML غير آمن.
